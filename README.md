# Nava

## Struttura

- `apps/api` — backend Fastify (TypeScript)
- `apps/web` — frontend React PWA
- `packages/shared-types` — tipi TypeScript condivisi
- `infra/terraform` — infrastruttura come codice
- `docs/adr` — Architecture Decision Records
- `docs/site` — pitch statico per investitori/organizzatori (base del futuro sito vetrina), apri `docs/site/index.html` in un browser

## Sviluppo

```
npm install
npm run dev
npm run test
npm run lint
npm run build
```
